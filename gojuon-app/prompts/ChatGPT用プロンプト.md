# 挿絵を ChatGPT で作るためのプロンプト集（10枚）

「リズムで あいうえお」の各行（あ行〜わ行）に1枚ずつ、
ジョジョの奇妙な冒険風（太い線・大げさなポーズ・「ゴゴゴ」の擬音）の挿絵を作るためのプロンプトです。

## 使い方

1. ChatGPT（画像生成ができるもの）を開きます。
2. まず下の「共通スタイル」を送り、続けて各行のプロンプトを1つずつ送ります。
3. できた画像を保存し、`images` フォルダに **下の表のファイル名で** 入れます。
   （同じ名前で上書きすれば、アプリ側の変更は不要です）
4. 画像は横長（4:3 くらい）がアプリの画面に合います。正方形でも表示はできます。

## 共通スタイル（最初に1回送る）

```
これから10枚の子ども向け絵本の挿絵を頼みます。すべて次のスタイルで統一してください。
・「ジョジョの奇妙な冒険」風：太いインクの輪郭線、細かいハッチング、大げさで決めポーズ、
　極端なパース、ビビッドな配色（オレンジ・マゼンタ・ターコイズなど）
・背景に大きく擬音「ゴゴゴ」を入れる（文字はそれ以外入れない）
・登場人物は小学生くらいの子ども。明るく元気で、こわい表情や暴力的な要素は入れない
・横長（4:3）、1枚に1場面
主人公は同じ子ども（短い黒髪、赤いバンダナ、黄色いシャツ）で統一してください。
```

## 各行のプロンプト

### 01 あ行 — 「あさだよ おはよう あいうえお／あかるい あさひが でてきたよ」
```
1枚目：朝。昇ってくる大きな朝日に向かって、主人公が両手を大きく広げて「おはよう」と叫んでいる決めポーズ。
まぶしい光の線と「ゴゴゴ」。
```

### 02 か行 — 「かさして かえろう かきくけこ／かぜが つよくて さむいなあ」
```
2枚目：強い風と雨の中、主人公が傘をぎゅっと握りしめ、風に逆らって前傾姿勢で帰り道を進む決めポーズ。
傘がしなり、落ち葉が舞う。「ゴゴゴ」。
```

### 03 さ行 — 「さかなが およぐよ さしすせそ／さらさら せせらぎ すずしいな」
```
3枚目：澄んだ小川のほとり。主人公が岩の上でしゃがみ、目を輝かせて泳ぐ魚たちを見つめている。
キラキラした水しぶき、涼しげな青と緑。「ゴゴゴ」。
```

### 04 た行 — 「たいこを たたこう たちつてと／とんとん たのしい たいこの おと」
```
4枚目：大きな和太鼓を、主人公がバチを振り上げて力いっぱい叩いている瞬間。
衝撃波のような線と「ドン」の代わりに「ゴゴゴ」。
```

### 05 な行 — 「なかよく ならんで なにぬねの／にっこり わらって なかまだね」
```
5枚目：主人公と友だち4人が横一列に並び、それぞれ違う決めポーズをとってニッコリ笑っている。
チームの登場シーンのような構図。「ゴゴゴ」。
```

### 06 は行 — 「はしって はねよう はひふへほ／はやいぞ ひろばを ひとまわり」
```
6枚目：広場を全力で走り、大きくジャンプする主人公。スピード線と残像、砂ぼこり。
ローアングルで足が画面に迫る構図。「ゴゴゴ」。
```

### 07 ま行 — 「まいにち まんぷく まみむめも／みんなで もぐもぐ おいしいな」
```
7枚目：大きなおにぎりやおかずが並んだ食卓で、主人公と友だちがほっぺをふくらませて「もぐもぐ」食べている。
おいしさで背景に光が差す演出。「ゴゴゴ」。
```

### 08 や行 — 「やさしく やろうね やいゆえよ／ゆっくり やれば できるよね」
```
8枚目：主人公が小さな子の手を取って、やさしく折り紙（または縄跳び）を教えている。
静かだけど決めポーズ感のある構図、あたたかい夕方の光。「ゴゴゴ」。
```

### 09 ら行 — 「らくらく ラーメン らりるれろ／るんるん りずむで つるつるっ」
```
9枚目：湯気の立つ大きなラーメンを、主人公が箸で高く持ち上げて「つるつるっ」とすする瞬間の決めポーズ。
麺が画面いっぱいに躍動する。「ゴゴゴ」。
```

### 10 わ行 — 「わらって わになる わをん／わいわい みんなで おどろうよ」
```
10枚目：主人公と友だちみんなが手をつないで大きな輪になり、笑いながら踊っている。
上から見下ろす構図で、輪の中心から光が広がる。「ゴゴゴ」。
```
