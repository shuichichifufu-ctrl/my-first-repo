# リズムで あいうえお（音読＋挿絵アプリ）

あ行〜わ行の10行を、絵本のように「挿絵」と「よむ文」が同じページに並んだ形で、めくりながら音読するアプリです。
ブラウザだけで動きます（サーバーやAPIキーは不要）。

## 使い方

- `index.html` をブラウザで開くだけで動きます。
- 画面の「‹ ›」ボタン、キーボードの ← →、スマホのスワイプでページをめくります。
- 上の「あ か さ …」ボタンで行にジャンプできます。
- 「🔊 おてほんを きく」でブラウザの音声がゆっくり読み上げます（1行だけ聞きたいときは、その行をクリック）。
- 「ページを開いたら自動でよみあげる」にチェックを入れると、よむページに来るたびに自動で読み上げます。

## 挿絵の入れ方

`prompts/ChatGPT用プロンプト.md` のプロンプトで ChatGPT に描いてもらい、
できた画像を `images/01_a.png` … `images/10_wa.png` の名前で保存してください。
同じ名前で置き換えるだけで、アプリ側の変更はいりません。

## 歌詞を直したいとき

`data.js` の `lines` の文字を書き換えてください。

## GitHub Pages で公開するとき

リポジトリの Settings → Pages で公開すると、
`https://<ユーザー名>.github.io/my-first-repo/gojuon-app/` で開けます。
