# CarryTrend EA（試作版）

スワップ（金利差）をプラスで受け取れる向きで、しかも12か月トレンドが同じ向きのときだけポジションを持つEAです。1日1回だけ判断します。根拠は `trading-research/REPORT.md` を見てください。

**期待値は「長期で小さくプラスになりやすい」程度です。** 過去27年の検証で年率+3〜4%（年10%の振れ幅のとき）、最大の落ち込み約−30%、負ける年も多くあります。

## 使い方
1. `CarryTrend.mq4` を MT4 の `MQL4/Experts` フォルダに入れ、MetaEditor でコンパイルします（**このファイルはまだコンパイル確認ができていません**。エラーが出たら内容を共有してください）。
2. 次のペアの日足チャートそれぞれに付けます：AUDJPY, NZDJPY, GBPJPY, EURJPY, CADJPY, USDJPY, AUDUSD, NZDUSD
3. まずはデモ口座で動かしてください。

## 主な設定
| 設定 | 既定値 | 意味 |
|---|---|---|
| Mode | キャリー×トレンド | 「キャリーのみ」「トレンドのみ」にも切り替え可 |
| CarryFrom | スワップから判定 | テスターでは「手入力」にする |
| ManualCarryDir | 1 | 手入力時の向き。1=買いでスワップがもらえる |
| MinCarryPct | 1.0 | スワップが年率1%未満なら持たない |
| TargetVolPct | 3.0 | 1ペアあたりの年間の振れ幅（口座の%）。8ペアで合計おおよそ年10%前後（推測） |
| MaxLots | 1.0 | ロットの上限 |
| StopATRMult | 6.0 | 非常用の損切り（日足の平均値幅の6倍）。0で無し |

## ストラテジーテスターで試すとき
- 期間は日足、モデルは「始値のみ」で十分です（1日1回しか判断しないため）。
- **テスターはスワップを今の値で固定して過去全体に当てはめます。** 過去の金利差は今と違うので、`CarryFrom=手入力` にして、検証期間の大半で金利の高かった側を `ManualCarryDir` に入れてください（例：AUDJPY・NZDJPYは2000〜2008年と2022年以降は 1）。
- 口座残高が小さいと最小ロットでも振れ幅が大きすぎ、EAは何もしません。
