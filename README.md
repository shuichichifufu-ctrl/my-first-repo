## ✕ボタンさがし れんしゅう（ad-close-game.html）

スマホゲームに割り込む広告の「本物の閉じるボタン」を探して押す練習ゲームです。1つのHTMLファイルだけで動き、外部との通信はありません。

- **開き方**: iPad の「ファイル」アプリから直接開くとプレビュー表示になり動きません。GitHub Pages などで公開した URL を Safari で開き、「ホーム画面に追加」して使ってください（ホーム画面に追加すると、Safari が保存データを 7日で消す仕様の対象外になります）。
- **ずかん**: タイトルの「📖 ずかん」に、まぎらわしいボタンを「まつ系・みつけにくい系・だます系・ずらす系・しつこい系・ストアから戻る・こまったとき」の7系統に分けた解説（見分け方・対策・先生向けの補足）があり、各項目の「ためす」でその例を1つ出せます。
- **記録**: プレイヤーごとに端末内（localStorage）に保存されます。「きろく」画面から JSON で書き出し・読み込みができます。
- **先生用**: タイトルの「⚙ せってい（先生用）」で、制限時間・✕の大きさ・使うパターン・レベルの上がり方・音などをモードごとに変えられます。設定で「先生用ボタンを隠す」にすると、画面上部の「れんしゅう」を 2秒長押しで開けます。

### 「こうこくの きまり」の出典

ずかんの「こうこくの きまり」で参照しているルールです（2026年9月時点。原文の変更に注意してください）。

- Apple「App Store 審査ガイドライン」2.5.18（広告）: https://developer.apple.com/app-store/review/guidelines/
- Google Play「デベロッパー ポリシー」広告の項、Better Ads Experiences（15秒以内に閉じられること、予期しないタイミングで出さないこと）: https://support.google.com/googleplay/android-developer/answer/9857753
- IAB Tech Lab「MRAID 3.0」（閉じる領域 50×50dp、推奨は右上。広告側が自前の閉じるマークを使うことも可）: https://iabtechlab.com/standards/mobile-rich-media-ad-interface-definitions-mraid/
- Google AdMob「インタースティシャル広告のガイダンス」「許可されない実装」（誤タップを誘う配置の禁止、閉じるボタンは最大5秒の遅延可）: https://support.google.com/admob/answer/6066980
- 日本インタラクティブ広告協会（JIAA）「広告フォーマットに関するガイドライン」: https://www.jiaa.org/katudo/gdl/format_gdl/
