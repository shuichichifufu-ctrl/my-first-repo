## ✕ボタンさがし れんしゅう（ad-close-game.html）

スマホゲームに割り込む広告の「本物の閉じるボタン」を探して押す練習ゲームです。1つのHTMLファイルだけで動き、外部との通信はありません。

- **開き方**: iPad の「ファイル」アプリから直接開くとプレビュー表示になり動きません。GitHub Pages などで公開した URL を Safari で開き、「ホーム画面に追加」して使ってください（ホーム画面に追加すると、Safari が保存データを 7日で消す仕様の対象外になります）。
- **記録**: プレイヤーごとに端末内（localStorage）に保存されます。「きろく」画面から JSON で書き出し・読み込みができます。
- **先生用**: タイトルの「⚙ せってい（先生用）」で、制限時間・✕の大きさ・使うパターン・レベルの上がり方・音などをモードごとに変えられます。設定で「先生用ボタンを隠す」にすると、画面上部の「れんしゅう」を 2秒長押しで開けます。
