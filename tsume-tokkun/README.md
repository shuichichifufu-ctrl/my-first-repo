# 詰将棋 格言特訓道場

詰将棋を「格言（詰め方の型）」ごとに集中して練習するための、1ファイルのアプリです。
`index.html` をブラウザで開くだけで動きます（インターネット接続は不要です）。

## 中身

| 道場 | 種類 | 問題数 | 手数 |
|---|---|---|---|
| 頭金 | 詰みの形 | 16 | 1手詰 |
| 腹金 | 詰みの形 | 16 | 1手詰 |
| 尻金 | 詰みの形 | 16 | 1手詰 |
| 玉は下段に落とせ | 格言 | 10 | 3手詰 |
| 金はとどめに残せ | 格言 | 10 | 3手詰 |

- 各道場の問題は、易しい順に並んでいます（駒の数と、王手の候補の数で決めています）。
- ヒント（3段階）、答えを見る、手順の再生、間違えた問題の復習、★の記録、称号があります。
- 「王手のしるし」は、王手になるマスに点を出す機能です。画面の下の「せってい」で切り替えられます。しるしなしで達成した★は金色、ありは銀色で記録されます。

## 確認できていること

- 全68問が、合駒（あいこま）を含む正式な規則で、次の3点を満たすことを、探索プログラムで確認しています。
  1. 詰むこと（手数が表示と一致し、より短い詰みがないこと）
  2. 初手が1つに定まること（余詰がないこと。玉方の全応手のあとも含む）
  3. 局面が合法であること（二歩や駒数の超過がないこと）
- 上の確認は、別の担当が自分で書いた独立の探索プログラムでも行い、全問で一致しました。
- 全問を、画面操作だけで最後まで解けることを、ブラウザの自動操作で確認しています。

## 確認できていないこと・限界

- 問題は、プログラムが自動で作って検証したものです。プロの作家の作品ではありません。詰め筋が似た問題もあります。
- 「格言に当てはまるか」の判定条件は、作成者が決めたものです。書籍によって解釈が異なる場合があります。
- 格言の意味づけは、次のページを参考に、作成者の言葉でまとめました。内容の照合は、検索結果の要約で行い、ページ全体の精読はしていません。
  - 将棋講座ドットコム「玉は下段に落とせ」「頭金」
  - ゼロから始める将棋研究所「金はトドメに残せ」
- 「金は斜めに誘え」「王手は追う手」は、意味を確認できなかったため、入れていません。
- 効果音は、音そのものを聞いて確かめていません（初期設定はオフです）。
- ChatGPTで作った画像は使っていません。見た目は、すべてコード（SVGとCSS）で描いています。
- 画面が小さい機器（幅320px×高さ568px）や、スマホの横向きでは、持駒が最初の画面に収まらず、下にスクロールが必要です（マスを44px以上に保つためです）。
- 盤は、問題に関係する部分（6〜7列）だけを切り出して表示しています。
- 学習の記録は、ブラウザの中（localStorage）に保存します。別の端末とは共有されません。

## 問題を増やす・作り直す

`tools/` に、問題の作成と検証のプログラム（Python）があります。`python-shogi` が必要です（`pip install python-shogi`）。

1. `gen.py` `gen2.py` `gen3.py` で、候補の問題を作る
2. `prefilter.py` で、すべての場合で正解が1つに定まる問題だけに絞る
3. `assemble.py` で、合駒を含む正式な規則の検証（`tsume_full.py`）を通った問題だけを選び、`app.tmpl.html` に埋め込んで `index.html` を作る

※ これは作成時の作業の流れです。途中で使うファイルの名前は、各プログラムの中に書かれています。

`tools/problems_meta.json` に、全68問の局面（SFEN形式）と、想定する初手・正解手順があります。別の探索プログラムで確かめることもできます。
