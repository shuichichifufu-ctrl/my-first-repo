## 山田さんの指示（原文の要約、番号は山田さんのまま）

### 1. サウンドとタイトル画面
- 1a プレイ中の BGM を設定画面で選べる。「げんき」「ゆかい」「のんびり」「いやし」の4曲。
  - いまのオルゴール調の静かな曲は「のんびり」か「いやし」として残す。
  - **既定は「げんき」**：運動会やパーティーのような元気で楽しい曲（戦いの雰囲気ではないもの）。
- 1b タイトル画面の並び
  - タイトルロゴ：画面の中央上部から、画面の真ん中あたりまで大きく。
  - 「はじめる」ボタン：画面下部の中央。
  - 「せってい」ボタン（歯車のアイコン）：画面の左上（ホームボタンは右上なので、左上に置く）。

### 2. 設定画面
- 2a 既定値の変更：「ソナーだけで さがす」をオン（search:'sonar'）、スワイプの向きは「反対」（swipeRev:true）。
- 2b スピード：「はやい」「ふつう」「ゆっくり」の3つから選べる。**いまの速さを「ゆっくり」にする。** ふつう＝×1.25、はやい＝×1.5。既定は「ふつう」。

### 3. マップ選択
- 3a 見本を大幅に増やす：四字熟語を増やす、小学生向けの「ことわざ」「英単語」を足す。
- 3b 横にスワイプ（スクロール）して次々に選べる並びにする。
- 3c 「ランダム」ボタン：見本の中から1つを自動で選んで始める。
- 3d 「絵を よみこむ」は残す。地図にするときの細かさを上げられるか検討。重くなる・固まるなら今のまま。

### 4. プレイ画面・操作感（重要度：高）
- 4a **最優先**：「すすむ」で前に進むとき、車体が斜めを向いて（横の星マークが見えて）右斜め前に進んでしまう。入力に対して車体がまっすぐ画面の奥を向き、まっすぐ進むようにする。3Dモデルの向きと進む向きを完全に一致させる。
- 4b 視点を4段階にする：「め」「おいかけ」「みわたし」（新しい。そらと おいかけの中間の、少し高い斜め見下ろしで地図全体が見やすい）「そら」。
- 4c 「おいかけ」ボタンの文字がはみ出している不具合を直す。
- 4d ソナーの正解演出：目的の宝の真上（いま下を掘れば出る位置）に着いたら「ピンピンピン」と知らせる効果音を鳴らす。
- 4e 左右のスワイプが反応しない・抜けることがあるので、確実に効くように判定と感度を上げる。

## 部品どうしの取り決め（CONTRACT.md にも「第5期の追加」として書く）

### Sfx（src/sfx.js）
- 新しい曲 4つを TRACKS に足す（ループ）：`genki`（げんき・既定）、`yukai`（ゆかい）、`nonbiri`（のんびり）、`iyashi`（いやし）。
  - `nonbiri` か `iyashi` のどちらかは、いまのオルゴール調の静かな曲（いまの play2 など、該当するもの）をそのまま、または少し整えて使う。
  - `genki`：運動会・パーティーの明るい行進／ポルカ風。テンポ 130〜145 くらい、長調、打楽器は軽く。短調・重い低音・戦いのような響きは使わない。
  - 4曲とも同じくらいの聞こえの大きさに（プレイ中なので小さめ。いまの play 曲の音量にそろえる）。
- `Sfx.PLAY_TRACKS = [{name:'genki',label:'げんき'},{name:'yukai',label:'ゆかい'},{name:'nonbiri',label:'のんびり'},{name:'iyashi',label:'いやし'}]` を公開する。
- 古い名前 `play1` `play2` `play3` で `bgm()` を呼んでも鳴るように残してよい（使わなくなるだけ）。
- 新しい効果音 `Sfx.play('pinpin')`：「ピン・ピン・ピン」と明るい高い音が3回（合計 0.6 秒くらい）。耳に痛くない。MIN_GAP は 1.0 秒以上。
- `Sfx.preview(name)`（あれば）：設定画面で曲を選んだときに数秒だけ試しに鳴らす。無くてもよい（UI は `bgm(name)` を呼んで、設定画面を出るときに `bgm('title')` に戻す）。

### World（src/world.js）
- `World.load(map, opts)` に `opts.speed: 'slow'|'normal'|'fast'` を足す。倍率 slow 1.0、normal 1.25、fast 1.5 を `SPEED`（2.88）、`AIR_SPEED`、`DA_SPEED` に掛ける。CPU も同じ倍率（人と同じ規則）。直進の加速（最大 +50%）はそのまま、倍率の上に掛かる。`World.SPEED_MUL = {slow:1, normal:1.25, fast:1.5}` を公開。
- カメラは 0〜3 の4つ：`0 め`、`1 おいかけ`、`2 みわたし`（新しい）、`3 そら`。`cycleCamera` は 0→1→2→3→0。いままで「2 = そら（真上）」として書いていた所はすべて 3 に直す。`World.camera` は 0〜3。
  - みわたし：シーカーの後ろの高めの斜め上から見下ろす（目安：仰角 50〜60 度、シーカーから 9〜12 マス離れる。向きは heading に従う）。地図のかなりの範囲が見え、シーカーも小さすぎずに見える。
- 4a の修正：「すすむ」を押したとき、車体の向き（3Dモデルの前）と進む向きが一致し、おいかけ視点ではまっすぐ画面の奥へ進む。原因を探して直す（候補：止まっているときに顔を見せるためにカメラが回りこむ処理 `orbitK` が、走り出しても戻らない／戻るのが遅い。モデルの前の向きが +Z から少しずれている。加速の向きの扱い。など）。直したら数値で確かめる（すすむを 2 秒押して、進んだ向きとモデルの向きとカメラの向きの差が 3 度以内）。
- 4d：自分のシーカーが「まだ誰も取っていない宝石の真上のマス」（宝石のあるマスと x,z が同じ）に入った瞬間に `emit('overGem', ti)` を出す。同じマスにとどまっている間は出さない。いったん出て別のマスに行き、また入ったら出す。空中にいる間は着地してから判定する。world が `Sfx.play('pinpin')` を自分で鳴らす（`sfx('pinpin')`）。光の柱モード・ソナーモードの両方で鳴らす。
- スワイプ：`World.swipeTurn(dx)` の感度（SWIPE_GAIN）は UI 側で倍率を掛けるので、world 側は変えなくてよい。ただし、空中・ドリル中・獲得宣言中以外は必ず回るようにする（回らない条件があれば UI 担当に分かるように報告）。

### MapGen（src/mapgen.js）
- PRESETS を増やす。`kind` は `'yoji'`（四字熟語）、`'kotowaza'`（ことわざ）、`'eigo'`（英単語）、`'illust'`（イラスト）。
  - 四字熟語：いまの 5 → 15 以上（小学校で習う・意味が前向きなもの。例：一石二鳥、十人十色、花鳥風月、春夏秋冬、東西南北、一生懸命、以心伝心、晴耕雨読、大器晩成、日進月歩、温故知新、起承転結 など）。
  - ことわざ：10 以上。長いので、地図にする字は短い形にする（例：「いそがば まわれ」「ちりも つもれば やまとなる」は長すぎるなら 2 行に）。字が地図の壁として成り立ち、宝の部屋に入れること（いまの四字熟語と同じ検査を通すこと）。
  - 英単語：10 以上（小学生向けの短い単語。CAT, DOG, SUN, STAR, APPLE, BOOK, FISH, TREE, MOON, BIRD など。大文字のローマ字で、読みはカタカナの `reading`、意味を `meaning`（例：'ねこ'）に入れる）。
  - それぞれの見本で、宝石10個が置けて、スタートから届くこと（いまの検査 mapgen4_test を広げて全部確かめる）。
  - 外へ出す一覧 `MapGen.presets` に `kind` と、あれば `meaning` を入れる。
- 3d：「絵を よみこむ」の地図の細かさ。いまの縦横のマス数を確かめ、上げられるなら上げる（目安：1.3〜1.5 倍）。ただし、3D世界の描画が重くならないこと（マス数の合計が増えるので、world4_run などで 1 コマの時間を比べる）。重くなるなら今のまま、と報告する。

### UI（src/ui.js、src/style.css、src/index.html）
- 設定の既定：`{ swipeRev: true, binary: false, level: 'normal', palette: 0, search: 'sonar', speed: 'normal', bgm: 'genki' }`。保存してある古い設定を読むと既定が効かないので、保存の名前（キー）を新しくする（v10 用）か、保存に版の番号を入れて、古い版のときは swipeRev と search だけ新しい既定にする。
- 設定画面に「スピード」（はやい／ふつう／ゆっくり）と「おんがく」（げんき／ゆかい／のんびり／いやし。選ぶと少し試しに鳴る）を足す。字の最小 3.4cqmin、重なりなし。
- プレイ開始で `Sfx.bgm(settings.bgm)`（ランダムはやめる）。通信対戦では、それぞれの端末が自分の設定の曲を鳴らしてよい。スピードはホストの設定を `map` の通信に入れて、両方が同じ速さにする。
- タイトル画面（1b）：ロゴを大きく、上の中央から真ん中あたりまで。「はじめる」は下の中央。歯車の「せってい」ボタンは左上（ホームボタンは右上のまま）。タイトルにほかのボタン（きろく など）があるなら、ロゴとはじめるに重ならない場所へ。重なりは数値で確かめる。
- マップ選択（3）：種類ごと（よじじゅくご・ことわざ・えいご・イラスト）に見出しをつけ、横にスクロールする1列のカードの並びにする（指で横にスワイプして次々に見られる。慣性スクロール、`scroll-snap`）。種類の切りかえタブを上に置いてもよい。「ランダム」ボタン（サイコロのアイコン）で見本の中から1つ選び、そのまま始める（または選んだ印をつける。いまの流れに合わせる）。「絵を よみこむ」は残す。英単語のカードには意味（例：ねこ）を小さく添える。
- 視点ボタン（4b, 4c）：4段階 `['め','おいかけ','みわたし','そら']`。ボタンの字がはみ出さないこと（いまは「おいかけへ」がはみ出している）。字の大きさを箱に合わせる、または字を短くする（例：視点の絵 ＋ いまの視点の名前）。4つの名前すべてで、字の幅がボタンの内側に収まることを数値で確かめる。
- 4d：world の `overGem` を受けたら、ソナーの表示を少し光らせる（点滅はしない。ふわっと明るくなって戻る）。音は world が鳴らすので UI では鳴らさない。
- 4e スワイプ：反応しない・抜ける原因を探して直す。候補：
  - なぞりの面（#swipe）がボタン以外の場所をきちんと覆っていない、ほかの要素の下になっている。
  - 動き出すまでのしきい値が大きすぎる、縦の動きが混ざると無視している。
  - `pointercancel` や `lostpointercapture` で途中で切れる。iPad Safari のジェスチャーに取られる（`touch-action: none` が要る）。
  - 2本目の指（すすむを押しながら、もう片方の手でなぞる）のときに受け付けていない。**すすむボタンを押したまま、別の指でなぞって向きを変えられること**が大事。
  - 感度：いまより回りやすく（目安：画面の横幅の 1/3 をなぞると 90 度）。
  - 直したら、Playwright で「すすむを押したまま、別の指（別の pointerId）でなぞる」確認を足す。

## 確かめること（セルフチェック）
1. 既定の曲が「げんき」で、4曲を設定で選べて、プレイで選んだ曲が鳴る。
2. タイトル：ロゴが大きく上中央〜真ん中、はじめるが下中央、歯車が左上。重なりなし（16:9 と 4:3）。
3. 設定の既定がソナーだけ・スワイプ反対・スピードふつう。古い保存が残っていても新しい既定になる。
4. スピード3段階が効く（ゆっくり＝いまの速さ）。CPU も同じ倍率。
5. 見本が 四字熟語15以上・ことわざ10以上・英単語10以上で、全部で宝石10個が置けて届く。横スクロールで選べる。ランダムが効く。
6. 絵を読み込む：細かさを上げたか、上げなかった理由が数値で言える。
7. すすむで まっすぐ奥へ進む（向きの差 3 度以内）。
8. 視点4段階、ボタンの字がはみ出さない。
9. 宝石の真上でピンピンピンが鳴る（1回だけ、入り直すとまた鳴る）。
10. すすむを押しながら別の指のスワイプで確実に回る。
11. エラーなし、e2e の通し確認が通る（必要なところは新しい仕様に合わせて直す）。言葉のチェック（つちのやま・ドリルジャンプ・まけ・ひきわけ が画面に出ない）は今までどおり。
