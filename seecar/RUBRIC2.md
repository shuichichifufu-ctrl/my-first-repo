# ほシーカー 採点表 第2版（第2期のラウンド1の前に固定。途中で書き換えない）

宣言：山田さんの修正依頼（SPEC2.md）で仕様が変わったため、RUBRIC.md から第2版に切り替える。第2期の点数は第1期（ラウンド1〜3、比較の回）とは別の系列として記録し、直接比べない。
比べる相手：山田さんの完成予想図（test/reference_concept.png）、SPEC.md と SPEC2.md の全項目。
合格の水準：特別支援学校の授業で、横向きのiPadを渡せば説明なしで遊べ、CPUと対戦して勝ち負けが分かる水準。
各観点10点満点。

## 1. 仕様の網羅（SPEC.md と SPEC2.md）
- 7点：SPEC2.md の12項目のうち、未実装または明らかに違う項目が1個以内。SPEC.md の項目（6ステート、ホームボタン、通信など）が壊れていない。
- 3点：SPEC2.md の未実装・仕様違いが5個以上。または以前あった機能が動かなくなっている。

## 2. 操作の分かりやすさ（スワイプ・ボタン・設定）
- 7点：スワイプで左右の向きと視点の上下が素直に動き、誤ってボタンや画面遷移が反応しない。操作ボタンを消しても遊べる。設定画面の項目はひらがなと絵で意味が分かり、押せる部品は画面短辺の8%以上。
- 3点：スワイプの反応が分かりにくい・効かない、設定の意味が分からない、ボタンを消すと遊べない。

## 3. 地形・宝・見本地図
- 7点：白黒モードで画像が高さ0と10の2段階になる。降りる段差の制限がなく、登りは1段まで。大砲は手前の1マスから1つずつ壊れる。見本地図が四字熟語（白黒）とイラストの両方あり、どれも宝が囲まれた領域の内側にあり、壁を壊せば行ける。
- 3点：白黒モードが効かない、大砲の壊れ方が仕様と違う、見本地図で宝に行けない・宝が壁の中。

## 4. 見た目と演出（完成予想図と並べて）
- 7点：遊んでいる視点で黒い壁の迷路と宝の光が見え、戦車は愛着の湧く形で撃つ向きが分かる。タイトル・設定・結果の画面がそろったデザインで、完成予想図と並べて「同じゲームの簡易版」と言える。
- 3点：迷路や宝が見えない、画面ごとにデザインがばらばら、戦車の向きが分からない。

## 5. 動作の安定と軽さ
- 7点：起動からCPU戦・宝発見・もう一度・終了まで、ひとり／CPU戦の一通りでコンソールエラーが出ない。地形はまとめて描画。連打・スワイプの連続で壊れない。
- 3点：エラーで止まる画面がある、CPU戦で固まる、連打で状態がおかしくなる。

## 6. 対戦（CPU・記録・通信）
- 7点：CPUが自分で道を探し、壁を大砲で壊して宝へ向かう。難しさ（速さ）で勝ちやすさがはっきり変わる。勝ち負けが数えられ、表示され、リセットできる（確認つき）。通信対戦も壊れていない。
- 3点：CPUがその場で止まる・同じ所を回る、難しさで差がない、勝敗が数えられない・消せない。

## 7. 誤操作の防止と表記
- 7点：全ボタンで stopPropagation と preventDefault（ファイル入力欄自体は例外）。スワイプが画面遷移や拡大を起こさない。ホームボタンと確認、縦持ち警告。和語はひらがな、外来語はカタカナ。リセットには確認がある。
- 3点：どれか1つでも抜けて誤操作で画面が飛ぶ、記録が誤って消える、漢字の多い表記が残る。

## 完成予想図の優れている点（毎ラウンド「勝っているか」を答える）
1. クレヨンで塗った紙の質感がそのまま立体迷路になっている
2. 赤と青の戦車が丸みのある愛着の湧く形で、色で区別できる
3. 「ドゴォーン！」の破壊演出が派手で気持ちよさそう
4. 壁が黒く太く、道が白で、迷路の構造が一目で分かる
5. 宝石が光っていて、目指す物がはっきりしている
