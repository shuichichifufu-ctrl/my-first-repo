# 仕様書（山田さん 2026-11-01 15:52 のメールより原文を整理）

特別支援学校向け教材「ツールキッチン」の一環。HTML/JS/CSSの単一ファイル。Three.jsとPeerJSはCDNから。

## ■1 ツールキッチン絶対厳守のUI/UX基盤
1. 画面レイアウト：100dvh、position:fixed; inset:0 で全画面固定。16:9のコンテナを中央、背景黒。cqmin等でどの画面サイズでもはみ出さない。
2. 縦持ち警告：@media screen and (orientation: portrait) で「スマホを横にしてね！」で覆う。
3. 誤操作防止：すべてのボタン操作・画面遷移のトリガーで必ず e.stopPropagation() と e.preventDefault()。
4. ズーム・メニュー防止：* { user-select:none; -webkit-user-select:none; touch-action:none; }。JSでcontextmenu無効化。
5. 6ステート：(1)Boot (2)Title (3)Setting（画像読み込み・通信待機） (4)Play（3D） (5)Ending（リザルト・宝発見） (6)Quit（終了画面）。
6. ホームボタン：右上の最上位レイヤーに白背景・円形で常時表示（safe-area-inset考慮）。押すと「終了しますか？（はい/いいえ）」モーダル、ゲームループの isPaused を切り替える。
7. 進行用ボタンの統一：ステート間の進行ボタンは最上位レイヤーの共通コンテナに置き、サイズとアニメーション（ホップ等）を統一。
8. 日本語表記：和語はひらがな、外来語はカタカナ（例：スタート→はじめる、クリア→みつけた！）。

## ■2 コアロジック
A. タイトル：「見つめて見つけてほシーカー（SEE-CAR）」。CSSで☆マークの中に「ほ」の字が入ったロゴ風タイトル。
B. 画像解析とマップ生成：設定画面で input type=file から塗り絵等を読み込む。Canvasで明度を0〜10の11段階に変換しボクセルの高さにする（白＝高さ0の道、真っ黒＝高さ10の壁）。画像の1単位を2×2のブロックとして配置し広大なマップに。
C. 宝の隠し場所：黒い壁（高さ10）に囲まれた白い閉鎖領域をすべて洗い出し、最も面積が小さい領域の中心に宝（宝石など）を置く。
D. シーカー：サイズ1×1（壁の1/4の面積）。Three.jsのプリミティブで、シンプルだが愛着の湧くタンク形状。他プレイヤーとは色で区別。ジャンプ不可。隣接マスとの高さの差が1以内なら滑らかに段差を登り降りできる。
E. 視点切り替え：UIボタンでカメラを滑らかに補間移動。(1)1人称 (2)斜め後ろ（マリオカート風、背後少し上） (3)俯瞰（ドローン風、高さ20から真下。全体マップと宝の位置が把握できる）。
F. 大砲：黒いボールが山なりの放物線で飛ぶ。射程固定。向いている方向の2つ隣のマス（1×1）に着弾し、そのマスとさらに1つ奥のマスの計2マスの高さを0にする。弾は他プレイヤーをすり抜ける。破壊の瞬間にパーティクル（破片）が飛び散る。
G. 通信対戦（PeerJS）：ホストとゲスト。毎フレーム地図を送らず、互いのシーカーの座標/向き/色/アニメーション状態と、地形破壊の座標（差分）のみ同期。
