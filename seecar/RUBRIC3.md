# 見つけて！PixSee 採点表 第3版（第3期のラウンド1の前に固定。途中で書き換えない）

宣言：山田さんの新しい依頼（SPEC3.md）でゲームの仕組みが変わったため第3版に切り替える。第3期の点数は第1期・第2期とは別の系列として記録し、直接比べない。
比べる相手：山田さんのデザイン画（ref_pixsee/seeker_design.png）と山田さんのシーカー3D（ref_pixsee/seeker3d.html）、元の完成予想図（test/reference_concept.png）、SPEC.md ■1 と SPEC3.md の全項目。
合格の水準：特別支援学校の授業で、横向きのiPadを渡せば説明なしで、コンピューターと「くらべっこ」の宝さがしが遊べる水準。
各観点10点満点。

## 1. 仕様の網羅（SPEC3 の11項目と ■1）
- 7点：SPEC3 の依頼11項目のうち、未実装・明らかに違うものが1個以内。■1 の8項目と、引き継ぐ機能（見本地図、白黒モード、記録とリセット、通信）が壊れていない。
- 3点：未実装・仕様違いが5個以上、または以前の機能が動かない。

## 2. シーカーのデザイン（山田さんのデザイン画・3Dとの一致）
- 7点：ロールケーキの円柱ボディ、端面のクリーム色の輪と白い穴とピンクの星、黒いバイザーに緑の目、水色と黄色のしましまのドリルハット、硬いキャタピラ、ボディとドリルの間の短い黒い棒があり、ドリルがボディにめり込んでいない。赤・青など相手と色以外でも見分けがつく工夫はなくてよいが、相手と区別できる。
- 3点：デザイン画と別物に見える、ドリルがめり込む、棒がない、キャタピラが柔らかく見える。

## 3. 動き（すすむ・ジャンプ・掘る）
- 7点：「すすむ」で画面の奥へ進み、スワイプで視点が回る。登りは1段、降りは自由。ジャンプは凹んでから弾むように跳ね、5段まで上がれ、前方ジャンプもできる。ドリルジャンプは回ってドリルを下に向け足元（または前）を掘る。ドリルアタックは正面を壊す。どれも見た目で何が起きたか分かる。
- 3点：跳ね方が硬い・高さが違う、掘れない・掘った結果が分からない、ドリルアタックとドリルジャンプの区別がつかない。

## 4. 宝さがしとソナー・モード
- 7点：宝が上から掘ると出てくる。左上のソナーが半径10ブロックの宝を上から見た円形で示し、向きが分かる。「どっちが はやい？」（宝1つ）、「どっちが おおい？」（宝10個・10分・残り時間と数が見える）、「ひとりで れんしゅう」が選べて最後まで遊べる。見本地図すべてで宝に行ける。
- 3点：宝が出ない・拾えない、ソナーが無い・合っていない、モードが欠けている、時間切れで終わらない。

## 5. くらべっこ（コンピューター・ともだち・記録）とことば
- 7点：コンピューターが自分で進み・跳び・壊し・掘って宝を集める。難しさで速さがはっきり変わる。スタートは公平。結果と記録が争いの言葉なしで伝わり、リセットできる。ともだちと あそぶ（通信）が壊れていない。画面のどこにも「たたかう」「バトル」「たいけつ」「大砲」「うつ」などの言葉がない。
- 3点：コンピューターが止まる・回り続ける、不公平、争いの言葉が残る、記録が数えられない。

## 6. 動作の安定と軽さ
- 7点：起動から各モード・結果・もう一度・終了まで、ひとり／コンピューターの一通りでコンソールエラーが出ない。地形はまとめて描画。連打・スワイプの連続・ジャンプ中の連打で壊れない。
- 3点：エラーで止まる、固まる、連打で状態がおかしくなる。

## 7. 誤操作の防止と表記、画面のデザイン
- 7点：■1 の誤操作防止（stopPropagation と preventDefault、ホームボタンと確認、縦持ち警告、拡大・メニュー防止）が守られ、和語はひらがな・外来語はカタカナ。左の「すすむ」と右の3つのボタンは大きく、絵で役割が分かり、押せる部品は画面短辺の8%以上。タイトル・選択・結果の画面がPixSeeのデザインでそろっている。
- 3点：誤操作で画面が飛ぶ、ボタンが小さい・役割が分からない、デザインがばらばら。

## 比べる相手の優れている点（毎ラウンド「勝っているか」を答える）
1. デザイン画のシーカーの愛らしさ（ロールケーキの体、星、緑の目、しましまドリル）
2. 山田さんの3Dのドリルの動き（逆さに回って潜って掘る、帽子のぷるぷる）
3. 元の完成予想図のクレヨンの紙の質感と立体迷路
4. 黒く太い壁と白い道で迷路が一目で分かる
5. 光る宝石で目指す物がはっきりしている
