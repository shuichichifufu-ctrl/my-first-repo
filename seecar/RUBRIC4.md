# 採点表 第4版（第4期 v9.0。SPEC4.md 対応。第1〜3期とは別系列）

各観点 0〜10 点。採点担当は作った経緯・前の点数を見ない。根拠（画面・数値・コードの場所）を必ず書く。

1. **共通仕様（§2）**：ホームボタンとモーダルが固定仕様どおり（位置・色・角丸・影・文言・タイトル/それ以外の動き・resetGame の初期化範囲・isPaused）、Boot（文面・じゅんびちゅう→タップしてスタート・click のみ・全画面と AudioContext）、署名コメントと v9.0 表記、contextmenu・html/body・user-select、文字の最小 3.4cqmin、.endpic とホームボタン。
2. **デザイン（§3）**：「ブロック世界のジオラマ」として、シンプルで世界に通用する質か。トークンの統一、タイトルの作り込み（ロゴ・奥行き・ゆっくり動く背景・ボタンの質感）、全画面の統一感、大きさ・コントラスト・点滅なし。
3. **シーカーの動き（§4-1〜4-4）**：速度 ×1.2、直進の加速（段・リセット条件・リセットしない条件・止まっている間の扱い・演出）、押し続けるドリルアタックの掘り進み、押し続けるジャンプドリル、名称。
4. **音（§4-2・§7・§8）**：キャタピラの段階音・旋回・衝突・段差・停止・ドリルへの置き換え、BGM（タイトル・プレイ3曲ランダム・小さめ）、ジングル4種、カウントダウン音、ファンファーレ、画面を離れたら止まる、曲データが配列。
5. **宝石と獲得（§5）**：ブロックの中に埋まる・到達できる・スタートから平面距離・10種類と色・重複なし、壊した人だけが獲得（横取り不可・通信はホスト決定）、3.5秒の宣言（文言・全員停止・ボタン無効・タイムは獲得の瞬間・ファンファーレ・やわらかい光）。
6. **CPU と さがしかた（§6）**：光の柱あり/なしの設定、CPU が宝の座標を読まない、ソナーの誤差、人と同じ規則と時間、CPU_LEVELS の1か所・コメント、3段階の強さの目安（特に むずかしい が弱すぎない）。
7. **演出と重なり（§1・§4-5・§7）**：擬音（立体的・短い・間隔）、カウントダウン（3・2・1・GO!・拡大・同期・止まる）、すべての絶対配置要素が重ならない（数値で）、引き分けの「へいわの しょうり」。
8. **こわれにくさ**：エラーなし、通し確認（ひとり・CPU・通信）、モーダル中にすべて止まって再開できる、resetGame 後にもう一度遊べる、言葉のチェック（つちのやま・ドリルジャンプ・まけ・ひきわけ が画面に出ない）。

合計は8観点の平均。SPEC4 §11 のセルフチェック9項目それぞれに「できた／一部／できていない」を付ける。
