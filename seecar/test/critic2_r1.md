## 完成予想図との比較

**完成予想図のほうが優れている。** v5 の遊ぶ画面は、白い床に黒い壁、桃色の光の柱だけの簡素な見た目で、完成予想図の楽しさ（クレヨンの紙、色とりどりの積み木、派手な演出）には届いていない。画面まわりのデザインは「同じゲームの簡易版」と言える水準。

| 完成予想図の優れている点 | v5 | 理由 |
|---|---|---|
| 1. クレヨンの紙の質感がそのまま立体迷路 | 負け | 床は白一色。紙やクレヨンの質感はない |
| 2. 丸くて愛着の湧く赤と青の戦車 | 負け | 赤・青で見分けられ、星の印もあるが、完成予想図ほど丸くなく存在感も弱い |
| 3. 「ドゴォーン！」の派手な破壊演出 | 負け | 文字の演出と破片はあるが、撮った画面では完成予想図ほどの迫力を確かめられなかった |
| 4. 黒く太い壁と白い道で迷路が一目で分かる | 勝ち | 黒と白だけなので、上からの視点では迷路の形が完成予想図よりはっきり分かる |
| 5. 光る宝石で目指す物がはっきり | 勝ち | 桃色の光の柱が遠くからでも見え、どこを目指せばよいか分かる |

## 次に直すべき最重要の1点

**遊ぶ画面（3D）の床と積み木に、紙とクレヨンの質感・色を付ける。**
理由：12項目のうち「できた」にならなかった中で、項目1（デザインを磨く）がいちばん目立ち、観点4（6点）が全体で最も低い。子どもが遊ぶ時間のほとんどはこの画面を見ていて、今は白一色の床がほとんどを占めている。

## 小さな修正点（5個）

1. やじるしボタンを「ださない」にすると「うしろ」も消え、後ろへ下がる手段がなくなる。また「まえ」が残るので仕様の文言と違う。設定の説明で断っているが、依頼者に確認が必要。
2. 四字熟語の地図は端末のフォント（太さ 900）で描いている。iPad で字の形・閉じた部分・宝の位置が変わらないかを実機で確かめる。できれば、字の形が端末で変わらない作り方にする。
3. 見本の四字熟語でも字のふちが灰色になり、高さ 1〜9 の小さな段ができる（自由自在は 166色）。白黒の見本なら、白と黒の2つに分けておくと迷路がきれいになる。
4. 上から見る視点で、自由自在の地図の右下半分が斜めに灰色になる（critic2_r1_ipad_sky_jiyu.png）。影の範囲が原因かもしれない。
5. 「ふつう」と「むずかしい」の差が約 1.3倍と小さい。また CPU は撃つ手間を軽く見ていて（BREAK_COST=2）、字の線をたくさんくりぬくので、遊び終わると絵が崩れる。壊す手間を重くするなどで、絵が残るようにしてはどうか。
