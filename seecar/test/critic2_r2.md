## 完成予想図との比較
**完成予想図の勝ち。** 迷路の分かりやすさと宝の目立ち方は成果物が上。ただ、完成予想図の「クレヨンの色の紙が立体になっている楽しさ」と「派手さ」には届いていない。

| 完成予想図の優れている点 | 勝ち負け | 理由 |
|---|---|---|
| 1. クレヨンの紙の質感がそのまま立体迷路 | 完成予想図の勝ち | 床は紙の質感だが、見本はすべて白黒で、クレヨンの色の立体は出てこない（依頼者の白黒の希望による部分もある）。 |
| 2. 赤と青の丸い愛着の湧く戦車 | 完成予想図の勝ち | 丸い形と色の区別はできている。ただ後ろから見ると砲身が見えず、顔のような表情もない。 |
| 3. 「ドゴォーン！」の派手な破壊 | 完成予想図の勝ち | 「ドゴォーン！」の文字と破片は出るが、短く小さい（0.8秒）。 |
| 4. 黒く太い壁と白い道で迷路が一目で分かる | 成果物の勝ち | 黒く太い壁と白い道だけなので、おいかけ視点でも空からの視点でも形がはっきり読める。 |
| 5. 光る宝石で目指す物がはっきり | 成果物の勝ち | ピンクの光の柱が壁の向こうからも見え、空からの視点では星の印が出る。 |

## 次に直すべき最重要の1点
**CPU戦のスタート位置を公平にする**（宝までの手数を自分とCPUでそろえる。または自分を近い側にする）。
今は自分がいつも「宝から遠い側」になり、自分の宝までの手数は、地図によってCPUの0.36倍〜2.15倍とばらばら（いえ 103手と48手、自由自在 28手と78手）。そのため、難しさを選ぶよりも地図を選ぶほうが勝ち負けに効いてしまう。「CPUと対戦して勝ち負けが分かる」という合格の水準と、項目10の意味がくずれている。
