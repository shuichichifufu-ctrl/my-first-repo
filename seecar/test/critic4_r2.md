## いちばん大きな残りの問題

**モーダルの「はい」（resetGame）や Quit →「はじめから」のあと、BGM とキャタピラ・ドリルの音が鳴らなくなる。**
原因は ui.js U21 の resetGame と modalYes('quit') が `isPaused=false` を入れるだけで `Sfx.pause(false)` を呼ばないこと。Sfx.stopAll は paused を残す作りなので、音量つまみが 0 のまま残る。教室では「1回タイトルへ戻ったら、それからずっと無音に近い」状態になり、§8 と §2-1 の両方に当たる。

## 直すべき点（優先順）

1. **resetGame と Quit の道で音の一時停止を解く**：resetGame の中で `call('Sfx','pause',false)` を呼ぶ（stopAll の前でも後でもよい）。または applyPause() を通して isPaused を false にする。modalYes('quit') も同じ。直したら「プレイ→はい→タイトルで BGM が鳴る→次のゲームで tread:true」を検査に入れる。
2. **CPU を弱める（特に むずかしい・ふつう）**：むずかしい の speed を 0.9 前後に、accelMax を 0.2 に、sonarErr.ang を 0.15 に、など。上の表と同じ比べ方で、ボットが むずかしい に 65% 前後勝つところを目安にする。やさしい（ひかりで）にも余裕を持たせる。
3. **CPU の円の外の情報を人と同じにする**：いちばん近い宝の向きだけを渡す（人のソナーのくさびと同じ）。
4. **獲得宣言のカメラ**：自分のシーカーと浮き上がる宝石が両方、壁にふさがれずに映る位置（少し上から、壁の外側）へ寄せる。宣言の札は少し下げるか小さくして、宝石が札の上に見えるようにする。
5. **市松模様の透かしをやめる**：カメラの前のブロックは、なめらかな半透明（不透明度 0.25〜0.35）にするか、カメラを持ち上げて避ける。
6. **4:3 のプレイ画面の上下の帯**：3D のキャンバスだけ #app 全体に広げる（UI は 16:9 の #stage のまま）。それができない場合は、帯の色を3Dの空と床の色に合わせ、境目をぼかす。
7. **タイトルの重なり**：記録チップを 1.5cqmin 下げる（bottom 8.4→6.8 前後）か、「せってい」の bottom を上げる。署名の行と重ならないことも確かめる。
8. **大きいお知らせの位置**：`#notice.big` の max-width を 70cqmin 以下にするか、top を 44cqmin 前後にして、操作ボタンにかからないようにする。
9. **ちずの名前の札が切れる**：max-width を広げる、よみを2行目に回す、文字を少しだけ小さくする（3.4cqmin は下回らない）、のどれか。地図カードのチェックの印は、カードの外側へずらす。
10. 通信中のモーダル：ホストが開いたら pause を送り、両方を止める（どっちがおおい？ のタイマーのずれを防ぐ）。CPU_LEVELS は ui.js か sfx.js より前のファイルへ移すと「先頭近く」になる。

## 実機（iPad）でしか確かめられないこと

- 音：BGM が小さめで落ち着いているか、効果音とのつりあい、キャタピラ音の段の違いが聞き分けられるか、止まるときのフェードが自然か。iPad の消音スイッチやバックグラウンドから戻ったときの AudioContext の再開。
- 操作感：「すすむ」を押しながらスワイプする2本指の操作、長押しの取りこぼし、ドリル・ジャンプドリルを押し続ける指の疲れ。
- 3D の重さ：128×128 の地図、破片や土ぼこりが多い場面、宣言中のフレームレート。発熱。
- safe-area：ノッチやホームバーのある機種で、ホームボタン・ソナー・操作ボタンが欠けないか。
- 4:3 の帯の見え方（直した場合も含めて）と、ホーム画面に追加して全画面で起動したとき。
- iPadOS で全画面がスキップされ、Boot から1回のタップで音が鳴り始めるか。
- 実際の子どもと遊んだときの CPU の勝率（特に やさしい と むずかしい）。
- 本物の PeerJS サーバー経由の通信（学校のネットワーク、遅延、切断と再接続）。
- 文字の読みやすさ（丸ゴシックの Hiragino Maru Gothic ProN での見え方と、宣言の文字が2行に収まるか）。
- 縦持ち・横持ちを切り替えたときの一時停止と再開。
