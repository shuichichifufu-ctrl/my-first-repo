# ほシーカー 採点表（ラウンド1の前に固定。途中で書き換えない）

比べる相手：山田さんの完成予想図（test/reference_concept.png）と、仕様書（SPEC.md）の全項目。
合格の水準：特別支援学校の授業で、横向きのiPadを渡せば説明なしで遊べる水準。
各観点10点満点。

## 1. 仕様の網羅
- 7点：SPEC.md の「■1」の8項目と「■2」のA〜Gのうち、未実装または明らかに仕様と違う項目が2個以内。違う箇所には理由がコメントか画面上で示されている。
- 3点：未実装・仕様違いが6個以上。または6ステートのうち欠けている画面がある。

## 2. 操作の分かりやすさ（特別支援の子どもが説明なしで使えるか）
- 7点：各画面で次に押すボタンが1つに絞られて目立ち、押せる部品はすべて画面短辺の8%以上の大きさ。プレイ画面の操作ボタンが絵（矢印・大砲など）で役割が分かり、押し続けたときの挙動が素直。
- 3点：押す場所に迷う、ボタンが小さい、文字だけで操作を説明している、押しても反応が分からない操作がある。

## 3. 画像から地形と宝の位置を作る正しさ
- 7点：白は高さ0、黒は高さ10、中間の明るさは段階的な高さになる。黒に囲まれた白い領域を正しく数え、ゴミのような小領域を除いた最小領域の内側に宝が置かれる。最初から入っている地図と読み込んだ画像の両方で成り立つ。
- 3点：高さの対応が崩れている、宝が壁の中や囲まれていない場所に出る、写真のような大きな画像で固まる。

## 4. 見た目と演出（完成予想図と並べて）
- 7点：塗り絵の色が地形に反映され、戦車が戦車だと一目で分かり愛着の湧く形。大砲の弾が山なりに飛び、着弾で破片が飛び散る。カメラ切り替えが滑らか。タイトルが☆の中に「ほ」のロゴになっている。完成予想図と並べても「同じゲームの簡易版」と言える。
- 3点：単色の箱の集まりに見える、戦車が箱1個、破壊の手応えが無い、カメラが瞬間移動する。

## 5. 動作の安定と軽さ
- 7点：起動から宝発見・終了・もう一度、までの一通りでコンソールにエラーが出ない。地図生成が数秒以内で、プレイ中のフレーム更新が途切れない（iPad相当でも動く描画量：個別メッシュではなくまとめて描画）。連打・同時押しで壊れない。
- 3点：エラーで止まる画面がある、地図が大きいと固まる、連打で状態がおかしくなる。

## 6. 通信対戦の同期
- 7点：ホストが部屋を作り、ゲストが短い番号で入れる。地図は接続時に1回送られ、以後は互いの戦車の位置・向き・色・動きの状態と、破壊した地点の差分だけが送られる。2画面で戦車の動きと破壊が一致する。切断時に子どもが困らない表示がある。
- 3点：つながらない、地図が食い違う、毎フレーム地図全体を送っている、切断で固まる。

## 7. 誤操作の防止と表記
- 7点：全ボタンで stopPropagation と preventDefault（ファイル選択の入力欄自体は例外）。右上のホームボタンが常に最前面で、「おわりにしますか？」の確認中はゲームが止まる。縦持ち警告が出る。拡大・長押しメニュー・文字選択が起きない。和語はひらがな、外来語はカタカナで、子ども向けの言葉になっている。
- 3点：どれか1つでも抜けて誤操作で画面が飛ぶ、漢字の多い大人向けの表記が残る。

## 完成予想図の優れている点（毎ラウンド「勝っているか」を答える）
1. クレヨンで塗った紙の質感がそのまま立体迷路になっている
2. 赤と青の戦車が丸みのある愛着の湧く形で、色で区別できる
3. 「ドゴォーン！」の破壊演出が派手で気持ちよさそう
4. 壁が黒く太く、道が白で、迷路の構造が一目で分かる
5. 宝石が光っていて、目指す物がはっきりしている
