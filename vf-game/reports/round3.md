## 計測方法と限界
- Playwright + chromium(swiftshader) で v3.html を実際に起動した。時間は論理フレーム(f.t など)で測った。
- ボット対戦と技の検証は、P1の入力欄(F[0].input)を毎論理フレーム書き込む方式で行った（キーボード経由ではない）。キーボード経由で確かめたのは次の範囲のみ。
  - Enterでタイトルから開始できた。
  - D前進、Q・Eの横移動が効いた。
  - J押下から1論理フレーム前後で攻撃状態になった。
  - J+Lの同時押しで「投げ」が出た。
- 「人間風ボット」は私が書いたスクリプトで、本物の人間ではない。タイムアップ判定は今回は確認していない。

### 1. 操作の反応 7点
- Jキー押下の直後（1論理フレーム前後）に state=attack になった。J+Lの同時押しで投げが出た。D・Q・Eの移動も効いた。
- 減点: Lを押しながらJを押すと必ず投げになるので、「ガードしたままパンチ」ができない。しゃがみ中は前後に歩けない。

### 2. 三すくみ 7点（ラウンド2の6点から上がった）
実測（攻撃側が1回ずつ、距離は技ごとの有効距離）で、受けたダメージは次のとおり。

| 防御 | パンチ(上段) | キック(中段) | ひじ(中段) | 下段キック |
|---|---|---|---|---|
| 立ちガード | 0 | 0 | 0 | 8 |
| しゃがみガード | 0 | 11 | 14 | 0 |
| ガードなし | 6 | 11 | 14 | 8 |

- 立ちガードは下段に、しゃがみガードは中段に負ける。上・中・下段の読み合いが成立している（ラウンド2で全部防げたしゃがみガードは直っている）。
- 投げはガード（立ち・しゃがみ）にも、しゃがみにも20ダメージ通る。距離1.2以内で当たり、1.3以上は空振り。
- 投げ入力の0〜6フレーム後にパンチを入れるとパンチが勝つ。7フレーム以降は投げが勝つ。
- 投げられる直前にしゃがむ・ガードしても投げは防げない。横移動は投げ入力後4フレーム以内なら投げをかわせた（8フレーム以降は20ダメージ）。
- 減点: 打撃の種類が少なく（上段1、中段2、下段1）、「ガードしたまま上段を出す」ができないため、攻め側の選択肢が狭い。

### 3. 技の手応え 7点
- 発生フレーム: パンチ6、下段9、キック11、ひじ13、投げ12。ダメージ6/8/11/14/20。
- ヒット時はヒットストップ、のけぞり姿勢、画面シェイク、体力ゲージの赤い減少表示が出る。ガード時は青い球と「ガード」の文字が出る（guarded.png）。
- 減点: ヒットのスパークは白・橙・緑・赤の単純な丸い球で、形は全部同じ（punch_hit.png, kick_hit.png）。ヒットとガードの違いは色と文字だけ。

### 4. CPUの強さと駆け引き 4点（ラウンド2の5点から下がった）
P1ボットを、CPU(P2)に対して実際に戦わせた結果（1戦=2本先取）。

| ボットの戦略 | P1の勝ち | 内訳 |
|---|---|---|
| 前進しながらJ/Kを交互連打 | 0勝/8戦 | 全戦0-2 |
| ガード固めだけ | 0勝/8戦 | 全戦0-2 |
| 棒立ち | 0勝/8戦 | 全戦0-2 |
| 近づいて横移動してから攻撃 | 0勝/8戦 | 全戦0-2 |
| **投げ連打(距離1.1以内でJ+L)** | **8勝/8戦** | 7戦2-0、1戦2-1 |
| **近づいてジャブ→ガードを繰り返す** | **8勝/8戦** | 全戦2-0 |
| 最大射程キック1発→後退（初版ボット） | 1勝/8戦 | ボットの出来が悪く参考値 |
| **最大射程キック1発→後退しつつガード（改良版）** | **10勝/10戦** | 8戦2-0、2戦2-1 |
| 人間風その1（攻撃を見て14フレーム後にガード、P/K/投げ/しゃがみ/横移動を巡回） | 0勝/8戦 | 全戦0-2 |
| **人間風その2（立ちガード待ち、12〜17フレーム遅れでガード反応、相手の硬直に最速技、ガード中の相手は投げ、ガードをしゃがみに切り替え）** | **20勝/20戦** | 18戦2-0、2戦2-1（10戦ずつ2回） |

- 良い点（測れた事実）: 連打・ガード固め・棒立ち・横移動してから攻撃では勝てない。
- 悪い点: 投げ連打、ジャブ+ガード、射程管理、人間風その2のどれでも、CPUは1戦も取れないか、ほとんど取れなかった。つまり「単純な戦略1つで完封」の状態が4種類ある。ラウンド2で「ジャブ+ガード」と「射程管理」を完封できる問題が指摘されたが、直っておらず、さらに投げ連打（ラウンド2は5勝/6戦、今回は8勝/8戦）と人間風その2が加わった。
- コード上の原因（読んで確認した範囲）: CPUが投げに反応して打撃を出す条件が `o.t > o.move.su`（投げが発生する12フレーム目より後）になっていて、投げが当たった後でしか反応しない。
- 「何をしても負ける」ではないが、連打で勝てない代わりに、簡単な型を1つ覚えれば完封できる。初心者が数回で勝てる水準は満たしているが、駆け引きは存在しない。

### 5. キャラの動きと見た目 6点
- 3D人型で肩・肘・股・膝・胴・首の関節がある。立ち、歩き、ガード、しゃがみ、パンチ、キック、下段、ひじ、のけぞり、投げられ、ダウン、勝ち、負けで姿勢が違うことを確認した。カメラは常に2人を画面に収めた。リングアウトでは落ちる様子が画面に残る（ringout.png）。ダウンは仰向けに寝る（matchend.png）。
- 減点: 胴体は箱で、立ち姿は色違いのみ。構えは両手を上げて立つだけで、体重移動は見えない。投げの掴み（grabbed.png）は、AKIRAが後ろに倒れて浮き、JACKYが片腕を前に出すだけで、手が相手に触れておらず組み合う絵にならない。しゃがみ中の上体はほぼ直立。

## 重点検証

### (a) 横移動で直線攻撃をかわせるか
攻撃入力の何フレーム後に横移動を始めたかで、かわせた（被ダメージ0）かを調べた。左右2回ずつ。

| 横移動の開始（攻撃開始に対して） | パンチ(6F) | キック(11F) | ひじ(13F) | 下段(9F) |
|---|---|---|---|---|
| 攻撃より6F前から押し続けている | 2/2 | 2/2 | 2/2 | 2/2 |
| 同時〜2F後 | 2/2 | 2/2 | 2/2 | 2/2 |
| 4F後 | 0/2 | 2/2 | 2/2 | 2/2 |
| 8F後 | 0/2 | 2/2 | 2/2 | 0/2 |
| 10F後 | 0/2 | 0/2 | 2/2 | 0/2 |
| 12F後以降 | 0/2 | 0/2 | 0/2 | 0/2 |
| 攻撃より前に横移動を止めている（攻撃開始時に相手が正面） | 当たる（攻撃は始動時の相手の位置を狙う） | 同左 | 同左 | 同左 |

- 先に押し続けていれば全技かわせ、緑のスパークと文字が出る。ラウンド2と同程度で、パンチは2F後、キックは8F後、ひじは10F後、下段は6F後までに押す必要がある。
- 「見てから動く」場合（人間の反応は約12〜15フレーム）は、4技のどれも0/2。見てからのサイドステップは実用にならず、読みの先出し専用。
- 横移動で投げは、投げ入力から4F後までならかわせた。

### (c) 投げ
- 見た目: 掴んだ瞬間に画面中央へ「つかまれた！ すぐ J+L で投げ抜け！」と大きく出る（grabbed.png）。手は相手に触れず、組み合っている絵にならない。投げが決まると相手は仰向けに飛んでダウンする（throw_air.png, downed.png）。
- 投げ抜け: 掴まれてから約18フレーム（0.3秒）の間にJ+Lで抜けられた。投げ入力の17〜34フレーム後に押すと抜けられ、1〜16フレーム後に押すと抜けられない（その間はまだ掴まれていない/自分が投げを出してしまうため）。ガードを押し続けている相手はJ単独で抜けられた。
- 評価: 窓は約0.3秒。案内文を読んでから押すのはぎりぎり。ただし、投げが「ガードされない・しゃがんでも通る」のに対して、投げ前にパンチを入れれば勝てるので、駆け引きとしては成立している。

### (d) ガードの上段・中段・下段の読み合い
上の「2. 三すくみ」の表のとおり、立ちガードとしゃがみガードで防げる技が違う。ただしガードを遅れて押した場合に間に合う窓は、攻撃入力の何フレーム後までかで、パンチ6F後、キック11F後、ひじ13F後、下段9F後まで。人間の反応（約12〜15フレーム）では、ひじだけがぎりぎり、他は見てからガードできない。

## 参照5点の勝ち負け
1. 3ボタン（パンチ・キック・ガード）だけで成立する読み合いの深さ: **負け**。上中下段と投げの三すくみは成立したが、CPUが投げ連打、ジャブ+ガード、射程管理、人間風その2のどれにも1戦も取れず、読み合いの深さに届かない。
2. 技ごとの発生・硬直・間合いが明確で見てから反応できる: **負け**。数値は技ごとに違うが、見てから反応できる技が（ひじを除いて）なく、サイドステップは4技とも見てからでは0/2。
3. 関節を持つ人型ポリゴンの重みのある自然な動き: **負け**。関節はあるが体重移動が見えず、胴は箱、投げの掴みで手が相手に触れない。
4. 横移動と3次元の駆け引き、リングアウト: **負け（差は縮まっている）**。先に動けば全部かわせ、リングアウトも映像として成立する。しかし見てからでは使えず、自分で歩いても落ちない。
5. 当たり・ガード・投げの判別しやすさ: **負け（差は小さい）**。ヒット・ガード・投げは文字とヒットストップで区別できるが、スパークは色違いの丸い球で、投げは組み合う絵がない。

## 次ラウンドで直すべき最重要の1点
**CPUを、単純な型1つで完封できない相手にする。**
- 実測: 「投げ連打」8勝/8戦、「ジャブ+ガード」8勝/8戦、「射程キック→後退しつつガード」10勝/10戦、「人間風その2」20勝/20戦。ラウンド2から「ジャブ+ガード」「射程管理」が直っておらず、「投げ連打」「人間風」でも負ける。三すくみは成立したので、次はCPUがそれを使い分けること。
- 直し方の方向: (1) 投げを警戒させる: 相手が投げ距離（1.2以内）に入ってきたらパンチ（投げ入力後6フレーム以内なら勝てる）か横移動を入れる。今は投げ発生（12F）の後に反応するので間に合わない。(2) ガード中の相手には立ち・しゃがみを見て下段・中段・投げを使い分ける（ガード固めに頼るだけにしない）。(3) 自分の攻撃がガードされた後・空振りした後は、反撃を受ける前に後退かガードを入れる。(4) 最大射程のキックには前進するか横移動で距離を詰める。

## 小さな修正（最大5つ）
1. ヒットとガードのスパークを形で変える（ヒットは星や線、ガードは盾型など）。今は色の違う丸い球だけ。
2. 投げの掴みの絵を直す。両者の腕が触れて組み合う姿勢にする。
3. 「Lを押しながらJ」で必ず投げになる入力を見直し、ガード中でもパンチを出せるようにする。
4. 見てから反応できる技を作る（予備動作の大きい技・発生の遅い技）。今は見てからのガード・サイドステップがほぼ不可能。
5. 歩いてリングの縁から自分で落ちられるようにするか、縁での攻防（リングアウトを狙う技）を作る。
