## 計測方法（実際に見えた・測れたもの）
- Playwright + chromium(swiftshader) で v2.html を実際に起動。時間は論理フレーム(f.t など)で測定。
- 状態の読み取りは window.__vf.F / game。ボットと各種テストは、P1側の入力を毎論理フレーム書き込む方式（__vf.F[0].ai を差し替え）で実施。キーボード経由ではない点は限界。キーボードでの確認は、Jキー押下から攻撃開始まで1論理フレーム以内であること、Enterによるタイトル開始・再戦、A長押しの後退のみ。
- 画面は技の発生直後で論理を止めて撮影（スパークは時間で消えるため、遅れて撮ると薄くなる）。

### 1. 操作の反応 7点
- J押下の次の論理フレームで state=attack になる（遅延1フレーム以内）。J+Lの同時押しで投げが出る。移動とガードの併用で取りこぼしは見つからなかった。
- 減点: Lを押しながらJを押すと必ず投げになり、「ガードしたままパンチ」ができない。しゃがみ中は歩けない（S+A/Dでしゃがみが解除される作り）。

### 2. 三すくみ 6点
実測（距離1.1〜1.5で各1回、体力変化を見た）:
- 立ちガード: パンチ・キック・ひじを全て防ぐ(ダメージ0)。下段キックだけ通る(8ダメージ)。
- しゃがみガード: パンチ・キック・ひじ・下段の全てを防ぐ(ダメージ0)。つまり「しゃがみガード」は打撃に対して下位互換のない完全防御で、上段と中段の区別は存在しない（ガード＋方向での上下の読み合いは成立していない）。
- 投げ: 立ちガード・しゃがみガードの両方に20ダメージ通る。ガードは投げに負ける。
- 投げの入力から6フレーム以内に相手がパンチを入力すると投げは潰れてこちらが8ダメージ(打撃が投げに勝つ)。8フレーム以降は投げが勝つ。投げ発生12F、パンチ6F。
- 減点: 上・中段の区別がなく、しゃがみガードが常に最適解に近い。

### 3. 技の手応え 7点
- 発生フレーム: パンチ6F、下段キック9F、キック11F、ひじ13F（MOVES定義とシーン計測で一致。ひじはさらに前進する）。ダメージ6/8/11/14、のけぞり技ごとに違う。
- ヒット時: 6Fのヒットストップ、画面シェイク、フラッシュ、のけぞり姿勢。カウンター時は8F停止と「カウンター」表示。ガード時は3F停止、青いスパーク、「ガード」文字。
- 投げ: 掴んだ時に「つかまれた！ すぐ J+L で投げ抜け！」が画面中央に出る(スクリーンショットで確認)。
- 減点: スパークは単色の半透明の丸い球で、技ごとに色と大きさが違うだけ（形・向きの違いはない）。撮影した画像でも、ヒット(白)とガード(青)は色以外ほぼ同じ見た目の球。

### 4. CPUの強さと駆け引き 5点
P1ボットを、CPU(P2)に対して実際に対戦させた結果（1戦=2本先取）:

| ボットの戦略 | P1の勝ち | 備考 |
|---|---|---|
| 前進しながらJ/Kを7フレームごとに交互連打 | 1勝/9戦（初回0/6、追加1/3） | 連打では基本的に勝てない |
| ガード固めだけ | 0勝/6戦 | 全戦0-2 |
| 投げ連打(距離1.15以内でJ+L) | 5勝/6戦 | |
| 近づいてジャブ→16Fガード→繰り返し | **9勝/9戦、全戦2-0（1本も落とさず）** | 追加3戦の被ダメージ内訳: CPUのキック89、ひじ72、パンチ6。投げによる被ダメージ0 |
| 横移動してからK/P | 4勝/6戦 | |
| 間合い管理(キック最大射程で1発、近すぎたら後退) | **6勝/6戦、全戦2-0** | |
| 人間風(攻撃を見たらガード、前進、P/K/投げ/横移動を巡回) | 0勝/6戦 | |
| 棒立ち | 0勝/6戦 | CPUの全勝 |

- 良い点（測れた事実）: 連打だけでは勝てない。棒立ち・ガード固めには勝つ。ラウンド1と違い、連打ボットが4勝0敗になる状態は解消された。
- 悪い点: 「ジャブを出してガードする」だけ、または「キックの最大射程で撃って下がる」だけで18本中18本を取り、CPUは1本も取れなかった。CPUは攻撃後の隙・ガード後の硬直を突かず、ガードしている相手に投げを決められなかった（追加3戦で投げのダメージ0）。何をしても負けるでも連打で勝てるでもないが、極めて単純な戦略で完封できる。

### 5. キャラの動きと見た目 6点
- 3D人型、関節あり(肩・肘・股・膝・胴・首)。立ち、歩き、ガード、しゃがみ、パンチ、キック、下段、ひじ、のけぞり、飛ばされ、ダウン、勝ち、負けで姿勢が違うことをスクリーンショットで確認。リングアウト時はカメラが落ちる側を追って、落ちる様子が画面に残る(ringout_fall)。
- 減点: 胴体は箱で、立ち姿は左右で色違いのみ。姿勢は線形補間で、体重移動は見えない。投げの掴み(throw_grab)は、AKIRAが腕を前に伸ばし相手が後ろにのけぞって浮くだけで、手が相手に触れておらず「組み合っている」絵にならない。しゃがみ姿勢は下半身がたたまれるだけで上体は直立に近い。

### 6. 勝敗の流れ 8点
実際に確認: 体力ゲージ(遅れて減る赤表示つき)、ROUND表示、60秒タイマー、タイムアップ(体力が多い側に1本、TIME UP)、KO(K.O.!とスロー、仰向けダウン)、リングアウト(RING OUT!、落下)、2本先取で「AKIRA WINS」と「Enter キーでもう一度」、Enterで再戦（ROUND 1・0勝0敗に戻る）。ボット対戦で再戦を50回近く繰り返してもエラーなし。
- 減点: 歩いてリングの縁に達しても止まるだけで自分からは落ちない(攻撃で飛ばされた時のみリングアウト)。

## 重点検証

### (a) 横移動で直線攻撃をかわせるか（各条件で12回 = 3技 × 左右 × 2回。かわした＝被ダメージ0）
| 条件 | パンチ(発生6F) | キック(11F) | ひじ(13F) |
|---|---|---|---|
| 横移動しない | 0/4 | 0/4 | 0/4 |
| 先に横移動を押している(攻撃の20F前から) | 4/4 | 4/4 | 4/4 |
| 攻撃の開始と同時に横移動 | 4/4 | 4/4 | 4/4 |
| 攻撃開始の4F後に横移動 | 0/4 | 4/4 | 4/4 |
| 攻撃開始の8F後に横移動 | 0/4 | 0/4 | 4/4 |
| 攻撃開始の12F後に横移動 | 0/4 | 0/4 | 0/4 |

- ラウンド1の0回から大きく改善した。先に動いている場合は全部かわせ、「かわした」の文字と緑のスパークも出る。
- しかし「見てから動く」場合は、人間の反応に近い12F(200ms)遅れで0/12。パンチは4F遅れで既に当たる。見てから横移動でかわせるのは、ひじ(8F遅れまで)とキック(4F遅れまで)だけで、実用上は読みの先出し専用。
- 後退歩きで、同時入力ならパンチ(距離1.3)もキック(距離1.7)もかわせた(0ダメージ)。しゃがみはパンチをかわしキックには当たる(11ダメージ)。

### (c) 投げ
- 見た目: 掴んだ瞬間、攻撃側は両腕を前に出し、掴まれた側は浮き上がって後ろにのけぞる(throw_grab)。手が相手に触れず、組み合っている絵にならない。投げが決まると相手は後方へ飛んで仰向けにダウン(throw_air, downed)。投げ抜けの案内文「つかまれた！ すぐ J+L で投げ抜け！」は画面中央に大きく出る(改善点)。
- 投げ抜けのしやすさ: 掴まれてから(掴みの停止4Fを除いた)約4〜20F以内に J+L で抜けられた。4F以降20Fまでの各遅延で全て成功、24F遅れは失敗(20ダメージ)。窓は約0.3秒で、案内文を読んでから押すのは間に合わない可能性が高いが、文字が出る前に反射的にJ+Lを押せるなら抜けられる。ガードを押し続けている相手はJ単独で投げ抜けできる（コード上、ガード中のJで成立）。

## 次ラウンドで直すべき最重要の1点
**CPUを、単純な戦略で完封できない相手にする（読み合いが存在する状態にする）。**
- 実測: 「ジャブ→ガード」だけで9戦9勝（18本中18本、被ダメージはCPUのキック・ひじ・パンチのみで投げは0）、「最大射程キック→後退」だけで6戦6勝。CPUは自分の攻撃がガードされた後の硬直や空振り後の隙を突かず、ガード中の相手を投げに行っても決められていない。
- 直し方の方向: (1) CPUの攻撃が防がれた/外れた後の自分の硬直中に反撃されるのを避ける動き(後退・ガード)を入れ、相手の硬直(blockstun中・空振り後)には素早く最速技を入れさせる。(2) ガードを一定時間続ける相手には、投げが届く距離(1.2以内)まで詰めてから投げる。(3) 最大射程キックに対し、前進して距離を詰めるか横移動する。これにより、ジャブ+ガードだけ・距離を取るだけでは勝てなくなり、横移動・投げ・ガード崩しを使い分ける動機が生まれる。

## 小さな修正（最大5つ）
1. しゃがみガードが上段・中段・下段の全てを防ぐ。立ちガードは上中段のみ、しゃがみガードは下段のみ（中段はしゃがみガードを崩す）にして、ガードに上下の読み合いを作る。
2. 見てから横移動でかわせる技を作る。パンチ(6F)とキック(11F)は予備動作の見た目が小さく、12F遅れで0/12。技の出始めに大きな予備動作（構え）を入れるか、発生を遅くした技を用意する。
3. 投げの掴みの絵を直す。掴んだ時に両者の腕が相手に触れ、組み合う姿勢（相手を掴んで持ち上げる）にする。今は手が相手に触れていない。
4. ヒット/ガードのスパークを形で区別する。ヒットは星型や線、ガードは盾型などにして、白い丸と青い丸の違いを色だけにしない。
5. 「Lを押しながらJ」で必ず投げになる入力を見直し、ガード中でもパンチを出せる、または投げを別操作にする（今は押しっぱなしのガードからパンチが出せない）。
