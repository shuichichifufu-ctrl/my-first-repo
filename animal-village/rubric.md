# 採点表（ラウンド1の前に固定・途中変更なし）

対象: ブラウザで遊べるスローライフゲーム「どうぶつの村」（単一HTML）
参照: 『あつまれ どうぶつの森』（実物は手元にないため、優れている5点との比較で代用）

## 参照の優れている5点
1. 画面全体が柔らかく色鮮やかで、どこを切り取っても絵になる
2. 歩く・釣る・虫を捕る等の一つ一つの動作に、音や動きの手応えがある
3. 住民が個性ある口調で話しかけてくれ、会うのが楽しい
4. 現実の時刻・季節と連動し、毎日違う発見がある
5. 急かされず、自分のペースで集める・飾る・育てる目的が次々に見つかる

## 観点（各10点満点）
1. 見た目のかわいさ・統一感
 7点: 配色が統一され、地面・水・木・住民・UIが同じ絵柄で描かれ、影や丸みで柔らかい。初見で「かわいい」と言える。
 3点: 単色の四角形が並ぶだけ。UIと世界の絵柄がばらばら。
2. 操作の心地よさ
 7点: 矢印/WASD/タップで滑らかに動き、障害物で引っかからず、操作説明なしでも最初の行動が分かる。スマホ・タブレットでも触れる。
 3点: 動きがカクつく、壁に引っかかる、何をすればいいか分からない。
3. 住民との交流
 7点: 住民が3人以上、それぞれ口調・性格が違い、会話が毎回同じでない。贈り物や頼みごとで関係が変わる。
 3点: 住民が立っているだけ、または全員同じ台詞。
4. 集める・育てる・飾る（のんびり続ける目的）
 7点: 釣り・虫採り・果実採集など3種類以上の採集があり、図鑑/コレクションで埋める目的があり、お金でできること（買い物・家の模様替えなど）がある。
 3点: 採集が1種類だけで、集めても何も起きない。
5. 時間・季節・天気の表現
 7点: 昼夜で画面の明るさが変わり、季節（または天気）で景色と出現物が変わり、時刻で住民の行動・台詞が変わる。
 3点: 時間の概念がない、または見た目が変わらない。
6. 手応え・演出・安定性
 7点: 動作ごとに音（WebAudio）と動き（効果・アニメ）があり、セーブ/再開でき、実行時エラーが出ない。
 3点: 無音、無反応、リロードで全消え、コンソールにエラー。
