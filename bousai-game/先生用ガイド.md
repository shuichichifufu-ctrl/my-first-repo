# 先生用ガイド：「ぽんたの ぼうさいむら」（地震の1章）

## ねらい
- 備蓄の「種類」と「量の考え方」（水は1人1日3リットル、最低3日・できれば1週間）を、ゲームの中で体験して覚える。
- 備えが足りないと何が困るかを、場面で体験する（暗闇・けが・トイレ・水・食べ物・寒さ・情報・こころ）。
- 備えは「当たり外れ」ではなく、何が起きるか分からないから幅広く必要、と気づく（毎回、起きる場面がランダムに変わる）。

## 対象と時間（案）
- 対象：小学校低・中学年。ひらがなが読めることが目安。読みにくい子は、読める子とペアにする（1台2人を推奨）。
- 時間の目安（未確認：実測していません。授業で測って調整してください）：導入5分 → 遊ぶ25分 → ふりかえり10分 → 発表5分。
- 端末：タブレットまたはパソコンのブラウザ（Chrome 推奨）。`bousai-game/index.html` をダブルクリックで開く。ネットにつながなくても動く（外部通信なし）。

## 始める前の確認（こわがる子への配慮）
- 地震の場面は、画面が揺れて大きな音が出ます。**遊ぶ前に「ゆれる がめんと おおきな おとが でるよ」と伝えてください。**
- 「ねる」を押すと、演出の選択カードが出ます。
  - 「おとありで すすむ」／「おとなしで すすむ」／「やさしい えんしゅつ（ゆれなし・おとなし）」／「まだ」。
  - 不安が強い子、感覚が敏感な子、地震を経験した子には、「やさしい えんしゅつ」を勧めてください。選んだ設定は端末に保存されます。
- 右上のスピーカー（🔊）でいつでも音を切れます。
- 災害の体験がある子がいる場合は、「いやな ときは やすんで いいよ」と先に伝えてください。「もどる」で、いつでも最初の画面に戻れます。

## ゲームの流れ
1. 3日間、村を歩いてどんぐり（おかね）を集め、お店で備蓄品を買う（そなえだなは14個まで）。
2. 3日目の夜に地震。最初の場面は必ず「地震の初動」（つくえの下で頭を守る）。残りは8種類から6つがランダム。
3. 結果画面：できたこと／つぎに そなえたいこと／おぼえておこう／おうちの人と話そう。

## ゲームの数字は「かんたんにした決まり」です
- みず：1ケース＝1日分（4人家族で1日12リットル、ペットボトル6本）。3ケース＝3日分。
- たべもの：1はこ＝1日分（ゲームの決まり）。実際の量・製品・栄養は、おうちの人と確かめるよう伝えてください。
- けいたいトイレ：1セット＝3日分（60回）。
- 結果画面にも「ほんとうの りょうは おうちの ひとと たしかめてね」と出ます。
- **公的資料（内閣府・農林水産省・東京都防災ブックなど）で最新の目安を確認してください。** 専門家レビューでも、ゲーム内の量は簡略化であることを注記するよう指摘がありました（原典はこちらで再確認していません）。

## ふりかえりの問い（例）
1. 「たりなくて こまった」のは、どの場面でしたか？ どうすれば よかったですか？
2. 今日は起きなかった場面（結果画面に表示）は、本当は起きるかもしれません。どれが大切ですか？
3. 家の「そなえ」と、逃げるときの「もちだしぶくろ」は、どう違いますか？
4. ゲームに出てこなかった備え（電池・現金・くすり・たなの固定・集合場所）は？
5. おうちの人と話すこと：「うちに いちばん ほしい そなえは なに？」

## 記録の扱い
- ベスト点と「むらの そだち」は、この端末のブラウザに保存されます。共用の端末では、タイトル画面の「きろくを けす」で消せます。
- ★の数の競争にならないようにしてください（毎回、場面の条件が違います）。
