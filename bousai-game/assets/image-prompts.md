# 品物の絵を ChatGPT に描いてもらう指示文

ゲームに出てくる13個の品物の絵を、ChatGPT（画像生成）で作るための指示文です。
出来上がった画像は、`assets/items/` フォルダに、下の「ファイル名」のとおりに保存します。

## 共通の条件（13個すべてに同じ）
- 正方形（1024×1024 の PNG）
- 背景は「真っ白」（#FFFFFF）。影は品物の足元に、ごく薄くだけ。
- 品物は1つだけ、真ん中に大きく。まわりに余白を残す。
- 文字・ロゴ・商品名・ブランド名は描かない（文字のない包装にする）。
- 絵のタッチは13個ぜんぶ同じにそろえる：**やわらかい手描き風の、子ども向け教材のイラスト。実物に近い形と色で、本物の防災グッズだと一目で分かるように描く。輪郭線は太めで茶色っぽく、色はあたたかくやさしい。**

## 共通の前置き（各指示文の頭に付ける）
```
子ども向けの防災教材に使う、やわらかい手描き風のイラストを描いてください。実物に近い形と色で、本物の道具だと一目で分かるように。輪郭線は太めの茶色っぽい線、色はあたたかくやさしい色。背景は真っ白、正方形、品物は1つだけを真ん中に大きく、足元に薄い影だけ。文字・ロゴ・商品名は入れない。
```

## 出来上がりの確認
- 13個ぜんぶ、絵のタッチ（線の太さ・色あい）がそろっているか。
- 背景が真っ白か（ゲームの画面では、白い部分が自然に溶け込むようにしてあります）。
- 文字やロゴが入っていないか。入っていたら、その品物だけ描き直し。
- 「緑の十字」「銀色の保温シート」など、何の道具か一目で分かるか。
