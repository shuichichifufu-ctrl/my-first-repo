# 採点表（ラウンド1の前に固定。途中で書き換えない）

対象: 地震の日を生き延びる、キャラ育成・物語型の非常食ゲーム（小学校低・中学年、ひらがな中心）
参照: どうぶつの森
水準: 授業で1コマ遊ばせて、子どもが自分から続きをやりたがる水準

## 参照（どうぶつの森）の優れている点5つ
1. 集める行為そのものが楽しい（音と手応え）
2. 住人が個性的で、話しかけるたびに違うことを言う
3. 急かされず、自分のペースで進められる
4. 色・丸み・音が一貫して、画面全体がやさしい
5. 集めたものが目に見えて増え、育った実感がある

## 観点（各10点）
1. 集める楽しさ
   - 7点: 備蓄品を1つ選んで手に入れるたびに、音と動きで手応えがある。集めた量が画面に見える。
   - 3点: ボタンを押すと数字が増えるだけで、手応えがない。
2. 住人・キャラクターの魅力
   - 7点: 住人が3人以上いて、口調と性格が違う。話すたびにセリフが変わる。
   - 3点: 全員が同じ調子で、同じセリフを繰り返す。
3. ほのぼのした画面と災害演出の落差
   - 7点: 日常はやわらかい色と丸い絵。地震の瞬間だけ、ジョジョ風の大きな文字と決めポーズに切り替わり、被害の絵は出ない。
   - 3点: 日常と災害で見た目が変わらないか、災害が怖い絵になる。
4. 学びの正確さ（内容の妥当性）
   - 7点: 備蓄の品目と量が公的資料と食い違わない。選び方の結果が、地震イベントで理屈どおりに出る。
   - 3点: 根拠のない品目や量があり、備えの結果がでたらめに見える。
5. 対象学年への適合
   - 7点: ひらがな中心で、初見の低学年が説明なしで次に押す場所を見つけられる。押す場所は44px四方以上。
   - 3点: 漢字と長い文が多く、押す場所に迷う。
6. 壊れにくさ
   - 7点: 連打、途中リセット、備蓄ゼロで災害が来る場合の分岐が書かれ、実行時エラーの箇所がない。
   - 3点: 連打や備蓄ゼロで画面が止まる、または外部URLに依存している。

## 実機確認待ちにする項目
触り心地・飽きにくさ・雰囲気は、ユーザーが触った報告を受けてから採点する。
