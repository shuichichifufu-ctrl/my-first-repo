# マイ換気扇

iPad（Safari）やパソコンのブラウザで動く、換気扇の教材アプリです。`index.html` を開くだけで動きます（インターネット不要）。

## できること

- スイッチと「風の強さ」で回す。回転数・1秒あたりの回転数・風の量（めやす）が見える
- 「使った年数」を動かすと、ほこり・黄ばみ・すり減りがいっしょに進む（新品〜20年）
- 「そうじ」でほこりだけ取れる（すり減りは戻らない）→ そうじの効果と限界を比べられる
- 「くわしく」で、ほこり・黄ばみ・じくうけ・モーター・ガタつき・音を1つずつ変えられる。力のつりあい（モーターの力／まさつ／空気のていこう）も見える
- プロペラとカバーのPNG画像を入れかえられる

## 画像の入れかえ

1. 「画像を入れかえる」を開き、「プロペラの見本を保存」「カバーの見本を保存」で下絵（600×600）を保存
2. 下絵をなぞって自分の絵を作る（背景は透明のPNG）
3. 「プロペラの画像」「カバーの画像」から選ぶ

決まり事:
- 画像の**まん中**がプロペラの回転の中心になります
- カバーの**すき間は透明**にすると、後ろのプロペラが見えます
- 大きすぎる画像は自動で小さくします（長い辺が1024ピクセルまで）
- 大きさが合わないときは「プロペラの大きさ」「カバーの大きさ」で調整

## 注意

- 回転数や風の量は、力のつりあいを単純にした計算でつくった**目安**です。実際の換気扇の測定値ではありません。
- 入れかえた画像は、ページを閉じるともとに戻ります（保存されません）。
